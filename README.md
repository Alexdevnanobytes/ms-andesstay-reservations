# ms-andesstay-reservations

Spring Boot Java 17 + Oracle. Ejecuta `mvn test` o `mvn spring-boot:run` con `DB_URL`, `RESERVATIONS_DB_USER`, `RESERVATIONS_DB_PASSWORD`, `CATALOG_URL` e `INTERNAL_TOKEN`. Escucha en 8081; solo debe ser accesible dentro de la red privada. Ver reglas y rutas en el README del paquete AndesStay.
